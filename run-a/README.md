# 五子棋 · 人机对战（原生 JS + ES Modules + Canvas）

一款打开浏览器就能玩的五子棋小游戏。纯前端、原生 JavaScript（ES6+ / ES Modules）、
HTML/CSS + Canvas 绘制，**不依赖任何构建工具和第三方库**，按职责拆分为多个模块文件。

## 运行方法

本游戏使用 ES Modules。浏览器出于安全策略不允许从 `file://` 直接加载模块脚本，
因此请用任意静态服务器打开（二选一即可）：

```bash
# 方式一：Python 3
python -m http.server 8000

# 方式二：Node.js（仓库自带，零依赖）
node serve.js 8000
```

然后浏览器访问 <http://localhost:8000> 即可开始游戏。

> 若直接用 `file://` 打开 `index.html`，页面会显示一个提示浮层，说明需要本地服务器。

## 玩法

- **人机对战**：玩家执黑先行，AI 执白。
- **双人对战**：两人同盘轮流落子，黑先白后。
- **落子**：鼠标点击棋盘的交叉点即可落子；鼠标悬停会显示落子预览。
- **难度**：简单 / 普通 / 困难，随时切换，下一手立即生效。
- **悔棋**：人机模式下点一次悔棋会回退双方各一步；双人模式回退一步；对局结束后悔棋可继续下。
- **重开 / 新对局**：清空棋盘开始新的一局。
- **每步计时**：勾选后显示当前这一手的用时。
- **棋谱复盘**：右侧「最近棋谱」列出最近 12 盘已结束对局，点「复盘」可逐手回放
  （支持首步 / 上一步 / 下一步 / 末步 / 进度条 / 自动播放 / 左右方向键）。

## 目录结构

```
index.html            页面骨架：棋盘、侧边面板、结算弹窗、复盘条
styles/main.css       全部界面样式
serve.js              零依赖静态服务器（可选，仅用于本地起服务）
src/
  main.js             入口：装配游戏与界面
  config.js           常量与配置（棋盘尺寸、颜色、存储键、难度枚举等）
  board.js            棋盘与落子规则（数据结构、落子、提子、边界判断）
  rules.js            胜负判定（横/竖/斜取连子，返回获胜连线）
  patterns.js         棋型打分（线提取、棋型匹配、增量盘面评估器）
  ai.js               AI 引擎（三档难度、候选点生成、alpha-beta minimax 搜索）
  record.js           棋谱与持久化（当前对局、历史棋谱、设置，基于 localStorage）
  timer.js            计时器（可暂停/恢复，用于切走时冻结计时）
  game.js             对局控制器（状态机、回合流转、悔棋、存档、驱动 AI）
  renderer.js         Canvas 渲染（棋盘、棋子、落子标记、五连高亮、落子预览）
  ui.js               游戏界面与交互（按钮、弹窗、提示、棋谱列表、复盘）
```

## 核心实现要点

**棋盘与规则**：`Board` 用一维 `Int8Array`（225 格）表示，`0` 空、`1` 黑、`2` 白。
所有非法落子（越界、重复落子、AI 回合、对局已结束）都会给出文字提示，不会静默失败。

**胜负判定**：`rules.js` 从最新落子出发，沿横、竖、两条斜线双向扫描，任一方向连续同色
棋数 ≥ 5 即判胜，返回整条连线用于高亮。棋盘下满且无五连判平局。

**棋型评估**：`patterns.js` 预生成全部直线，将线映射为棋型字符串后按优先级匹配并即时
消耗已匹配片段，识别连五、活四、冲四、活三、眠三、活二、眠二等棋型并加权。
`Evaluator` 维护每条线的分数，落子时只重算经过该点的 4 条线，评估复杂度为 O(1)。

**AI 引擎**（`ai.js`）：

- 简单：以随机选点为主，只会拦堵明显的成五点（能一步取胜时必定取胜）。
- 普通：棋型启发式评估 + 浅层搜索（2 层 negamax），会主动做活二、活三。
- 困难：带 alpha-beta 剪枝的 minimax（迭代加深至 6 层）+ 完整棋型评估，
  候选点按启发式排序并限制分支宽度。

困难档采用迭代加深 + 时间预算控制：每步总预算 1.5s，且每搜索一个根节点最多连续占用
线程 300ms，随后 `await` 让出主线程，因此「每步思考不超过 2 秒」且思考期间界面不会卡死
（配合 CSS 动画的思考指示器）。

**存档与复盘**：落子后自动把当前对局写入 `localStorage`（只保存每手的坐标，不保存棋盘
快照）；关闭页面再打开可恢复未完成的对局；对局结束后写入历史棋谱列表（最多 12 盘），
可逐手复盘。悔棋、重开、切模式等操作都会同步更新存档。

**性能**：AI 搜索全程复用预分配缓冲区（候选点数组、棋盘标记、各层候选缓冲），
每步结束不残留对象；棋谱只保留坐标，历史列表有上限，长时间游玩不会持续占用内存。

**窗口切换**：`visibilitychange` 时暂停总计时与每步计时，切回来恢复到原状态，不会偷偷走表；
若切走时轮到 AI，AI 的思考会延后到页面可见后再进行。
